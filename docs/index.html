Use the same API in your own site:

import { convertAudioToVcb, loadVcbFromFile, speak } from "./js/vcb.js";

const { blob, voice } = await convertAudioToVcb(audioBlob, { voiceName: "alice" });
// download blob as alice.vcb

const v = await loadVcbFromFile(vcbFile);

Python (optional):

pip install vcb
vcb convert recording.wav -n my-voice
vcb speak my-voice.vcb "Hello" -o out.wav

How it works

1
Record or upload clear speech in the browser.
2
JS extracts pitch, formants, spectral features and MFCCs, packs them into a .vcb binary (same format as Python).
3
Load the .vcb and synthesize any text in the browser or with Python.
