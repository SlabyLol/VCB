VCB

Record speech → create a portable .vcb voice → make it speak any text

Python package Browser API MIT · DarkFox

1 Record your voice

Speak clearly for 10–30 seconds. The recording is saved as a WAV file that you can convert to .vcb with the Python package.

00:00

2 Convert to .vcb (Python)

Full voice analysis needs the Python package. Run this on your machine after downloading the recording:

pip install vcb
vcb convert your-recording.wav -n my-voice -o my-voice.vcb

Or in Python:

from vcb import convert_audio_to_vcb
convert_audio_to_vcb("your-recording.wav", voice_name="my-voice")

3 Load .vcb & Speak

Upload a .vcb file and type any text. The browser synthesizer will speak with that voice.

How it works

1
Record or provide a clear speech sample (MP3 / WAV).
2
The Python package extracts pitch, formants, MFCCs and spectral features and packs them into a compact .vcb binary file.
3
Load the .vcb in Python or in the browser and synthesize any text with the characteristics of that voice.
